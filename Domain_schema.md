# Rental Housing Listing Schema

My entity is a rental housing listing.

## Fields
- id: numeric identifier for the rental listing
- propertyTitle: title of the rental listing
- location: location of the rental property
- submitterEmail: email of the person submitting the listing
- description: description of the rental property
- propertyType: type of rental property
- termsAccepted: whether the user accepted the terms
- submissionDate: date and time the listing was submitted

## Categories
- Apartment
- House
- Condominium
- Townhouse
