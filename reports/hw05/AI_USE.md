# AI use

I mainly used AI for code debugging. I also used it to understand some concepts step by step and to clarify which screenshots and evidence the homework required. I personally ran the code, tests, experiments, database checks, and MCP calls, and I captured and checked the screenshots.

One generated agent response included an unsupported unit count and a street address. I found that by comparing the response with the logged execute_tool result. I tightened the grounding instruction, reran the scenarios, and checked them again.
